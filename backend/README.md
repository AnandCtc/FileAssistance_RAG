# RAG Assistant Backend

This backend service provides file upload, validation, processing, and persistence support for the RAG File Assistant project.

## Structure

- `src/main/java/com/example/ragassistant` - application code
- `src/main/resources` - runtime configuration and uploads directory
- `pom.xml` - Maven build configuration

## Run

Use `./mvnw spring-boot:run` from the `backend` directory.
